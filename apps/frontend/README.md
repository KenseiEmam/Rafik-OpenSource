# Frontend application

This workspace contains the Vue 3 and TypeScript web app, Vite build, feature modules, and browser checks. It shares transport contracts and generated database types through [`@rafik/shared`](../../packages/shared/).

Install dependencies once from the repository root with `npm ci`. From the root, use `npm run dev`, `npm run build`, `npm test`, and `npm run test:e2e`. The app uses the root `.env.local`, generated by `npm run web-env`; see the [root quick start](../../README.md) and [local runbook](../../docs/operations/README.md).

After sign-in, each account opens its assigned role dashboard. An institutional account has one role; administrators manage invitations and role changes in **People & access**, review recorded activity in **Analytics**, and create and publish plans in **Programs**. Trainers and athletes receive their own task navigation. Role-specific routes are authorized by the server; visual navigation is not the security boundary.
