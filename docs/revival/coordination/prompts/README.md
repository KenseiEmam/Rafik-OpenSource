# Agent Prompts

Use these files when assigning work to agents.

- `GENERAL_AGENT_INSTRUCTIONS.md`: common instructions for every agent
- `AGENT_01_PROMPT.md`: Agent 1 prompt
- `AGENT_02_PROMPT.md`: Agent 2 prompt
- `AGENT_03_PROMPT.md`: Agent 3 prompt
- `AGENT_04_PROMPT.md`: Agent 4 prompt

Every agent should read the general prompt plus its own agent-specific prompt.
