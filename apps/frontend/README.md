# Frontend application

This workspace contains the Vue 3 and TypeScript web app, Vite build, feature modules, and browser checks. It shares transport contracts and generated database types through [`@rafik/shared`](../../packages/shared/).

Install dependencies once from the repository root with `npm ci`. From the root, use `npm run dev`, `npm run build`, `npm test`, and `npm run test:e2e`. The app uses the root `.env.local`, generated by `npm run web-env`; see the [root quick start](../../README.md) and [local runbook](../../docs/implementation/runbook.md).
