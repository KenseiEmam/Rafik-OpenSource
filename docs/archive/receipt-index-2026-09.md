# Historical check receipt index

This index describes the older R1–R13 artifacts retained under [`verification/receipts/`](../verification/receipts/). Their counts are dated history, not current acceptance evidence. Current verification is summarized in [`docs/verification/README.md`](../verification/README.md); older narrative results are in [verification history](verification-history-2026-10-17.md).

The directory contains sanitized text logs and JSON layout/release reports from the earlier gym-first development. Do not use those artifacts to infer current product scope or release readiness. See the receipt's recorded phase and source snapshot before using any number.
