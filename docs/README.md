# Documentation

This documentation records the approved university-first direction and staged migration plan. It distinguishes existing local behavior from proposed work.

- [Requirements and staged plan](requirements/README.md): goals, current-state audit, stages, acceptance criteria, risks, and privacy/security gates.
- [Architecture](architecture/README.md): current component boundaries and the target self-hosted deployment model.
- [ADR 0001: University-owned isolated deployments](decisions/ADR-0001-university-owned-deployments.md): deployment, data ownership, identity, sensitive records, support, and open decisions.
- [Testing and verification](testing/README.md): current local commands, scope, and evidence limits.

The backend architecture, runbook, verification record, role-scope audit, and historical decisions are under [`backend/docs`](../backend/docs). They describe the current implementation and must be reconciled with the approved university-first product direction.
