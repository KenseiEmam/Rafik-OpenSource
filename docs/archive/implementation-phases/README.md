# Historical implementation phases

These R-numbered files record phase-specific design decisions and local acceptance from the earlier gym-first implementation. They are retained as historical evidence, not as the current product plan or onboarding guide. Some policies and features were superseded or removed.

For current product scope, permissions, operations and verification, use the maintained [requirements](../../requirements/README.md), [architecture](../../architecture/README.md), [operations guide](../../operations/README.md) and [verification summary](../../verification/README.md). The [development ledger](../../development/ledger.md) identifies the current stage and open gates.
