# R5: integrated product quality and exercise choice

Local scope. No hosting, payment/notification adapter or native work. Apply the contribution definition of done, user-task audit and release checklist.

## Exercise alternatives and actual substitutions

A coach can offer up to three distinct, active, accessible alternatives per prescribed exercise. Alternatives must use the same recording kind (strength, timed or distance). They inherit the prescribed set count/targets/rest; the editor and client clearly say this. This is a bounded coaching choice, not a generated recommendation.

Publication freezes each alternative's exercise instructions/media alongside the original. Started prescriptions remain immutable. A client chooses an approved alternative for the entire exercise occurrence; the actual choice is recorded on its set entries and uses the existing durable local save/receipt protocol. Returning to the original is explicit. Switching does not erase recorded values or completed flags; the UI warns that existing results remain and may need correction. No extra completion/progression is generated.

The server rejects unapproved choices, mismatched choices across sets, inaccessible/retired draft alternatives, duplicates and cross-kind choices. Old plans/sessions/device records without alternatives continue to work. Operation hashes already include entries, so the same operation ID cannot be reused for a different choice.

Workout display, coach review, previous performance and progress identify the exercise actually performed while keeping the original target visible. Shared-plan import and coach handoff clone alternatives into independent coach ownership. Export inherits the stored prescription snapshots and entry choices.

## Integrated quality work

Fix Messages as a bounded, searchable inbox/thread workspace with reachable composer, phone back navigation, optional file attachment UI, retained exact-send recovery and visible-history read cursors. Late polls must not update an unmounted screen. Preserve paging and scroll position.

Review all existing feature families in realistic populated and empty states. Fix long check-in lists, Today priority and misleading unselected-client states. Document findings and concrete results rather than equating test counts with usability.

## Acceptance

Coach authors/publishes alternatives; client chooses and records offline, retries after reconnect/lost acknowledgement, completes/corrects; coach review/progress and next-session prior performance use the chosen exercise. Original snapshot and completion date remain unchanged. Import/handoff preserve usable independently owned alternatives. Invalid choices and other-account access fail transactionally.

Run complete existing regressions, additional choice/paging/composer/failure scenarios, fresh database/upgrade checks and actual rendered inspection. Physical-device usability, hosting and human task observation remain separate release gates.
